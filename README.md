# DraftCellar

Runs a customizable, self-contained, version control system for writers and researchers with a simple GUI interface.

With DraftCellar, you get a lightweight tool that stays out of your way.

**What you get**

- Runs a customizable, self-contained, version
- control system for writers and
- researchers with a simple GUI

## Key Features

- Runs a customizable, self-contained, version
- control system for writers and
- researchers with a simple GUI

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftCellar.git`
2. `cd DraftCellar`
3. Install in editable mode: `pip install -e .`

## Configuration

DraftCellar is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
